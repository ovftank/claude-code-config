# pi-config

My [pi](https://pi.dev/) + [herdr](https://herdr.dev/) setup.

<br />

## Install

Run this to install:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/ovftank/pi-config/main/.github/install.ps1 | iex"
```

## Keybinds

### pi

**Chat**

| Action               | Keys                                              |
| -------------------- | ------------------------------------------------- |
| Send message         | <kbd>Enter</kbd>                                  |
| New line             | <kbd>Shift</kbd>+<kbd>Enter</kbd>                 |
| Interrupt (stop)     | <kbd>Esc</kbd>                                    |
| Queue follow-up      | <kbd>Ctrl</kbd>+<kbd>Enter</kbd>                  |
| Restore queued       | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd> |
| Clear editor / exit  | <kbd>Ctrl</kbd>+<kbd>C</kbd> (press twice)        |
| Paste image/text     | <kbd>Ctrl</kbd>+<kbd>V</kbd>                      |
| Model selector       | <kbd>Ctrl</kbd>+<kbd>P</kbd>                      |
| Cycle thinking level | <kbd>Shift</kbd>+<kbd>Tab</kbd>                   |

**Transcript** (fullscreen scrollback)

| Action          | Keys                                                        |
| --------------- | ----------------------------------------------------------- |
| Scroll 1 line   | <kbd>Ctrl</kbd>+<kbd>J</kbd> / <kbd>Ctrl</kbd>+<kbd>K</kbd> |
| Search          | <kbd>Ctrl</kbd>+<kbd>F</kbd>                                |
| Next / prev hit | <kbd>Enter</kbd> / <kbd>Shift</kbd>+<kbd>Enter</kbd>        |
| Close search    | <kbd>Esc</kbd>                                              |

**Editor**

| Action       | Keys                                                                     |
| ------------ | ------------------------------------------------------------------------ |
| Move by word | <kbd>Ctrl</kbd>+<kbd>←</kbd> / <kbd>Ctrl</kbd>+<kbd>→</kbd>              |
| Delete word  | <kbd>Ctrl</kbd>+<kbd>Backspace</kbd> / <kbd>Ctrl</kbd>+<kbd>Delete</kbd> |
| Undo         | <kbd>Ctrl</kbd>+<kbd>Z</kbd>                                             |

### herdr

**Keybinds**

| Action              | Keys                                                                             |
| ------------------- | -------------------------------------------------------------------------------- |
| New tab             | <kbd>Ctrl</kbd>+<kbd>T</kbd>                                                     |
| Close tab           | <kbd>Ctrl</kbd>+<kbd>W</kbd>                                                     |
| Next / previous tab | <kbd>Ctrl</kbd>+<kbd>Tab</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> |
| Jump to tab 1–9     | <kbd>Ctrl</kbd>+<kbd>1</kbd>…<kbd>9</kbd>                                        |
| Paste               | <kbd>Ctrl</kbd>+<kbd>V</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd>     |

**Mouse**

| Action       | How                       |
| ------------ | ------------------------- |
| Rename a tab | double-click the tab      |
| Reorder tabs | drag a tab                |
| Switch tabs  | scroll over the tab strip |
